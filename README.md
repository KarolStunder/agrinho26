# 🌱 Agro Forte, Futuro Sustentável

## 📖 Sobre o Projeto

O projeto **Agro Forte, Futuro Sustentável** foi desenvolvido durante as aulas de Programação ministradas pela **Professora Regiane**, com o objetivo de demonstrar como a tecnologia e a sustentabilidade podem trabalhar juntas para transformar o agronegócio moderno.

A proposta consiste na criação de um website interativo, moderno e responsivo que apresenta conceitos relacionados à agricultura sustentável, inovação tecnológica no campo, manejo inteligente de recursos naturais e práticas que contribuem para a preservação ambiental sem comprometer a produtividade agrícola.

Além dos conhecimentos adquiridos em sala de aula, foram utilizadas ferramentas de **Inteligência Artificial** como apoio para pesquisa, organização de ideias, aprimoramento do design e otimização do código, sempre sob análise e adaptação da desenvolvedora para atender aos objetivos do projeto.

---

# 🎯 Objetivos

* Demonstrar a importância da sustentabilidade no agronegócio.
* Apresentar tecnologias utilizadas na agricultura moderna.
* Incentivar o uso consciente dos recursos naturais.
* Desenvolver habilidades práticas em HTML, CSS e JavaScript.
* Aplicar conceitos de design moderno e experiência do usuário (UX/UI).
* Criar uma interface visualmente atrativa e responsiva.

## CSS3

Responsável pela estilização completa da página.

### Recursos aplicados:

* Variáveis CSS (`:root`)

---

## JavaScript

Responsável pelas funcionalidades dinâmicas da aplicação.

### Funcionalidades implementadas:

### 📊 Contadores Animados

Os indicadores numéricos da seção de estatísticas aumentam automaticamente quando aparecem na tela.

Exemplos:

* 45% de aumento na produtividade
* 30% de economia de água
* 85% de energia renovável utilizada

### 👀 Intersection Observer

Foi utilizada a API **Intersection Observer** para detectar quando os elementos entram na área visível do navegador, iniciando as animações apenas no momento adequado.

### 🌙 Sistema Dark Mode

Implementação completa do modo escuro com:

* Alternância por botão
* Troca dinâmica de ícones
* Salvamento da preferência do usuário utilizando Local Storage
* Persistência da configuração mesmo após atualizar a página
